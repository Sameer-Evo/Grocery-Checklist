# 🛒 Grocery List Tracker

A simple and user-friendly **Grocery List Tracker** that helps you organize your grocery shopping by adding items, tracking quantities, and marking items as completed.

The project is designed to make grocery planning simple, quick, and convenient.

## 📌 About the Project

The Grocery List Tracker allows users to create and manage their grocery list in one place.

Instead of keeping a handwritten list or trying to remember everything while shopping, users can add their required grocery items, specify quantities and units, and check them off as they shop.

The application provides a clean and responsive interface that can be used comfortably on both desktop and mobile devices.

## ✨ Features

* 📝 Add grocery items to your list
* 🔢 Specify quantity for each item
* 📏 Select the appropriate unit
* ✅ Mark grocery items as completed
* ❌ Remove items from the list
* 📊 Track total, remaining, and completed items
* 🧹 Clear completed items
* 🌙 Light and dark mode
* 💾 Save grocery list data locally
* 📱 Responsive design for mobile and desktop
* 🔗 Share your grocery list
* 📴 Works offline
* 📲 Can be installed as an app on supported devices

## 🛍️ How It Works

### 1. Add an Item

Enter the name of the grocery item you need.

For example:

```text
Milk
Rice
Tomatoes
Eggs
```

### 2. Set Quantity

Add the required quantity and select a unit.

For example:

```text
Milk     → 2 L
Rice     → 5 kg
Eggs     → 12 pcs
```

### 3. Track Your Shopping

As you purchase each item, mark it as completed.

The tracker automatically keeps track of:

* Total items
* Items remaining
* Items completed

### 4. Complete Your Shopping

Once all items are checked, the application shows that your grocery list is complete.

The Grocery List Tracker stores the grocery list locally in the browser.

This means your list can remain available when you return to the application without requiring an account or a backend database.
